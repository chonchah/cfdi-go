# Security Policy

## Reporting a vulnerability

Si encuentras una vulnerabilidad de seguridad, **no** la reportes en un issue público. Envíala de forma privada a través de las GitHub Security Advisories o contacta a los mantenedores directamente.

Por favor incluye:

- Descripción de la vulnerabilidad
- Pasos para reproducirla
- Impacto estimado
- Posible sugerencia de corrección (opcional)

## Responsive disclosure

- Tu reporte será confirmado lo antes posible.
- Trabajaremos en una corrección y publicaremos un aviso cuando esté lista.
- No divulgues públicamente el problema hasta que se haya publicado la corrección.

## Defenderemos

- Dependencias con vulnerabilidades conocidas
- Exposición de datos sensibles o credenciales
- Inyecciones (SOAP/XML) y parseo de XML no seguro
- Problemas de autenticación/autorización en el servicio
